# AI Team Project Entry Point

This project uses the namespaced `ai-team` layout. The canonical delivery artifacts live under `.ai-team/`.

Read `.ai-team/manifest.md` first, then follow the paths and workflow in `.ai-team/project-rules.md`. All AI delivery artifacts must live under `.ai-team/`; do not create root-level `docs/`, `tasks/`, `discussions/`, or `scripts/` trees for this workflow.
